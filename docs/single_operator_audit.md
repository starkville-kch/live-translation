## 승인 후 적용할 화면 초안

지금은 위 표에 해당하는 추가 정리를 적용하지 않았습니다. 핵심 조작을 위로 모으고, 비용·재연결·세부 지연은 접힌 진단 영역으로 모으는 안입니다. 고정 모델과 자동 동작은 평상시에 선택할 필요가 없습니다.

```text
+-----------------------------------------------------------+
| 스타크빌 한인교회             [오디오 정상] [통역 중] [가이드] |
+-----------------------------------------------------------+
| [시작 / 일시정지 / 재개]   [서비스 종료]        [프로그램 종료] |
| 입력 장치: [마이크 선택] [새로고침]    레벨: ========          |
| 출력 언어: [x] English  [ ] 한국어  [ ] 기타                 |
+-------------------------------+---------------------------+
| 실시간 원문 / 번역             | 참석자 접속               |
|                               | [현장 Wi-Fi] [공용 링크]  |
| [예상 밖 언어: 출력 숨김]      | QR / URL / 크게 보기      |
|                               | 접속자 수                 |
| [통역 듣기]                   |                           |
+-------------------------------+---------------------------+
| > 진단: 연결 / 네트워크 / 재연결 / 비용 / 이벤트 로그        |
+-----------------------------------------------------------+
```

녹음은 캡처와 함께 자동으로 동작하고 실패할 때 경고하므로, 별도의 녹음 버튼이나 설정은 추가하지 않습니다. 위 표의 추가 삭제·통합·이동은 승인 후 별도 작업으로 진행합니다.

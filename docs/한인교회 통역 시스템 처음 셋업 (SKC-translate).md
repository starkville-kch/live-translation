# 한인교회 통역 시스템 처음 셋업

**SKC Live Translation 설치와 첫 사용 안내**

v3.4.4 · 2026-11-09

SKC Live Translation은 예배를 실시간 자막과 음성으로 통역하는 Windows 프로그램입니다. 처음 사용할 때 교회 이름, 로고와 접속 주소를 설정하면 다른 교회에서도 사용할 수 있습니다.

처음 설치하는 경우에도 Python이나 Conda를 따로 설치할 필요가 없습니다. `SKC_setup.exe`를 실행한 뒤 아래 순서대로 진행해 주세요. 설정 파일을 직접 열어 수정하지 않아도 됩니다.

예를 들어 Jackson Korean Church에서는 다음과 같이 설정할 수 있습니다.

```text
교회 이름: Jackson Korean Church
약칭: JKC
현장 접속 주소: http://jkc.local:8080
```

설정은 처음 한 번만 하면 됩니다. 이후 예배 때는 `SKC_translation.exe`를 실행하면 됩니다.

## 1. 압축을 풀고 설정 프로그램을 실행합니다

다운로드한 ZIP을 새 폴더에 풀어 주세요. 압축 파일 안에서 프로그램을 바로 실행하지 말고, 압축을 푼 폴더를 먼저 엽니다.

그 폴더에서 다음 파일을 실행합니다.

```text
SKC_setup.exe
```

설정 화면이 열리면 먼저 교회 정보를 입력합니다. Google API 키는 다음 단계에서 준비하므로 아직 없어도 괜찮습니다.

> 기존 버전을 교체하는 경우에는 먼저 이전 프로그램을 종료해 주세요. 이전 폴더는 그대로 보관하고, 새 폴더에 기존 `.env`, `config.yaml`, `branding/`을 복사하면 설정을 이어서 사용할 수 있습니다.

## 2. 교회 이름과 현장 주소를 입력합니다

화면 왼쪽의 **1. CHURCH & LOCAL NETWORK**에서 교회 정보를 입력합니다.

예를 들어 다음처럼 입력할 수 있습니다.

```text
Church Name: Jackson Korean Church
Short Name: JKC
Local URL: jkc
```

**Church Name**에는 교회 정식 이름을, **Short Name**에는 휴대폰 화면에 표시할 짧은 이름을 입력해 주세요.

**Local URL**에는 `jkc`처럼 짧은 이름만 입력합니다. 옆에 표시되는 `.local:8080`은 프로그램이 붙여 주므로 다시 입력하지 않아도 됩니다. 위 예시의 전체 주소는 `http://jkc.local:8080`입니다.

교회 로고가 있으면 **Choose Logo...** 버튼을 눌러 파일을 선택해 주세요. 입력한 교회 이름과 로고는 통역 화면에 사용됩니다.

**Operator Pass**는 운영자 화면에 로그인할 때 사용할 비밀번호입니다. 선택 사항이므로 로그인 없이 사용하려면 비워 두어도 됩니다. 비밀번호를 설정했다면 운영 담당자만 보관해 주세요.

## 3. Google AI Studio를 엽니다

이 프로그램은 Google Gemini로 통역합니다. 처음 한 번은 Google 계정에서 API 프로젝트와 결제를 준비해야 합니다.

설정 화면 오른쪽에서 다음 버튼을 눌러 주세요.

```text
Open Google AI Studio
```

웹브라우저에 Google AI Studio가 열리면 교회에서 계속 관리할 Google 계정으로 로그인합니다.

이미 유료 Gemini 프로젝트와 API 키가 있다면 4번과 5번은 건너뛰고, 6번에서 그 키를 입력하면 됩니다.

## 4. 프로젝트와 결제를 준비합니다

AI Studio에서 사용할 프로젝트를 선택합니다. 프로젝트가 없다면 새로 만들어 주세요. 이름은 교회에서 알아보기 쉽게 정하면 됩니다.

예:

```text
JKC-Live-Translation
```

선택한 프로젝트에서 **Set up billing**을 눌러 결제 계정을 연결합니다. 화면의 안내에 따라 국가, 주소와 결제수단 등을 입력해 주세요.

**Prepay** 또는 크레딧 충전 화면이 나오면 화면에 표시된 금액과 조건을 확인한 뒤 충전합니다. 이 금액은 Gemini API를 사용할 비용을 미리 충전하는 것입니다.

충전한 금액에서는 실제 API 사용 비용이 차감됩니다. 남은 크레딧은 이후 예배에서도 사용할 수 있습니다. 잔액이 부족하면 통역이 중단될 수 있으므로 예배 전에 AI Studio의 Billing 화면을 확인해 주세요.

Google의 결제 화면이나 조건은 바뀔 수 있습니다. [Google 결제 안내](https://aistudio.google.com/docs/billing)와 실제 화면에 표시된 내용을 기준으로 진행해 주세요.

## 5. API 키를 만들고 복사합니다

AI Studio의 **API Keys**에서 **Create API key**를 선택합니다. 앞에서 결제를 연결한 프로젝트를 선택해 키를 만들어 주세요.

키가 만들어지면 **Copy**를 눌러 복사합니다.

API 키는 비밀번호처럼 보관해 주세요. 교회 홈페이지, 공개 문서, 단체 대화방이나 참석자용 안내문에는 넣지 않습니다. 참석자에게는 나중에 만드는 QR 코드와 접속 주소만 안내하면 됩니다.

기존에 잘 작동하는 유료 프로젝트의 키가 있다면 그대로 사용해도 됩니다. 새 키를 만들 때는 [Google API 키 안내](https://ai.google.dev/gemini-api/docs/api-key)도 참고할 수 있습니다.

## 6. API 키를 붙여 넣고 연결을 확인합니다

`SKC_setup.exe`로 돌아와 **2. GOOGLE GEMINI API**의 API Key 입력란에 복사한 키를 붙여 넣습니다. 키는 화면에서 가려져 표시됩니다.

그다음 다음 버튼을 눌러 주세요.

```text
Test Connection & Model Availability
```

프로그램이 Google에 접속해 키 인증과 통역 모델의 사용 가능 여부를 확인합니다. 하단에 초록색 **Gemini verified**가 나타나면 연결 확인을 통과한 것입니다.

노란색 **API key set**은 키가 입력되었다는 표시입니다. 아직 시험하지 않았다면 위 버튼을 눌러 확인해 주세요.

오류가 나오면 키가 빠짐없이 복사되었는지, PC가 인터넷에 연결되어 있는지, 선택한 프로젝트의 결제가 준비되었는지 확인합니다.

## 7. 공용 HTTPS는 필요한 경우에만 설정합니다

참석자가 교회 Wi-Fi에 연결해서 사용할 예정이라면 **3. PUBLIC HTTPS (Advanced)** 영역은 건너뛰어도 됩니다. 처음에는 현장 Wi-Fi로 시작하는 것이 간단합니다.

LTE/5G나 교회 밖에서도 접속하게 하려면 이 영역을 펼칩니다. 이때는 Cloudflare 계정, 도메인과 설정된 터널이 필요합니다.

공용 URL과 터널 토큰을 입력하고, 필요한 경우 **Download cloudflared.exe**로 접속 프로그램을 받습니다. 자세한 준비 과정은 [Cloudflare 안내](https://developers.cloudflare.com/tunnel/get-started/)를 참고해 주세요.

영역을 펼친 뒤 `Checking...`이 잠시 보일 수 있습니다. Windows 서비스 상태를 확인하는 중이며 다른 입력은 계속할 수 있습니다. 화면 아래쪽이 보이지 않으면 스크롤해 주세요.

공용 HTTPS는 참석자 접속용입니다. 운영자 화면은 PC나 교회 Wi-Fi에서 엽니다.

## 8. Save & Finish로 설정을 저장합니다

입력과 연결 확인이 끝나면 화면 아래의 **Save & Finish**를 눌러 주세요.

교회 정보와 API 키가 저장되고, 같은 폴더에 다음 두 파일이 만들어집니다.

```text
qr_local.png
qr_local_print.html
```

`qr_local.png`는 TV나 주보에 사용할 QR 이미지입니다. `qr_local_print.html`은 교회 이름, QR 코드와 접속 안내가 들어 있는 인쇄용 페이지입니다.

여기까지 하면 처음 설정은 끝입니다. 이제 QR 안내문을 준비하고 휴대폰으로 접속해 보면 됩니다.

## 9. QR 안내문을 인쇄하거나 저장합니다

폴더에서 `qr_local_print.html`을 더블클릭합니다. 열린 페이지에서 **인쇄 / Print**를 누르거나 `Ctrl+P`를 눌러 주세요.

인쇄 미리보기에서 A4 또는 Letter 용지를 선택하고 한 장에 맞는지 확인합니다. 프린터로 출력해도 되고, 인쇄 대상에서 **PDF로 저장**을 선택해 보관해도 됩니다.

QR 이미지만 필요하면 `qr_local.png`를 사용하면 됩니다.

프로그램 실행 중에도 운영자 화면의 **접속 QR 코드**에서 저장하거나 인쇄할 수 있습니다.

- QR 이미지를 마우스 오른쪽 버튼으로 눌러 **이미지를 다른 이름으로 저장**을 선택합니다.
- **현장 Wi-Fi QR 안내문 인쇄**를 누른 뒤, 열린 창에서 **안내문 인쇄**를 누릅니다.
- 공용 접속을 설정한 경우에는 **현장 Wi-Fi**를 선택합니다. 인쇄 버튼에는 **공용 & 현장 QR 둘 다 보기 (인쇄용)** 문구가 표시될 수 있습니다.

이 QR은 통역 화면의 접속 주소를 담고 있습니다. 참석자는 먼저 교회 Wi-Fi에 연결한 뒤 스캔해 주세요. QR을 스캔하는 것만으로 Wi-Fi에 연결되지는 않습니다.

## 10. 예배 전에 휴대폰으로 확인합니다

PC에서 다음 파일을 실행합니다.

```text
SKC_translation.exe
```

운영자 화면이 열리면 사용할 마이크를 선택하고 **번역 시작**을 누릅니다. 실제 예배에서 사용할 언어로 한두 문장씩 말해 원문과 번역이 나오는지 확인해 주세요.

휴대폰을 교회 Wi-Fi에 연결한 뒤 QR을 스캔합니다. 자막이 보이고 번역 음성이 들리는지 확인합니다. 음성을 들을 때는 이어폰을 사용해 주세요.

> 휴대폰이 QR 주소에 접속하려면 PC와 통역 프로그램이 실행 중이어야 합니다. 현장 Wi-Fi로 접속하더라도 PC는 Gemini 통역을 위해 인터넷에 연결되어 있어야 합니다.

휴대폰에서 주소가 열리지 않으면 같은 Wi-Fi인지 먼저 확인해 주세요. 운영자 화면의 현장 IP 주소로도 접속해 볼 수 있습니다. 게스트 Wi-Fi는 기기 간 접속을 막는 경우가 있으므로 교회 네트워크 담당자에게 확인하면 도움이 됩니다.

## 11. 매주 예배 때는 이렇게 사용합니다

처음 설정을 마친 뒤에는 매주 설정 프로그램을 실행할 필요가 없습니다.

1. PC와 휴대폰의 네트워크 연결을 확인합니다.
2. `SKC_translation.exe`를 실행합니다.
3. 마이크를 선택하고 **번역 시작**을 누릅니다.
4. 짧게 말해 자막과 음성을 확인합니다.
5. QR 코드로 참석자의 접속을 안내합니다.
6. 예배가 끝나면 **서비스 종료**를 누르고 프로그램을 종료합니다.

잠깐 통역을 쉬려면 일시정지 후 재개할 수 있습니다. 이때 통역 문맥과 입력 녹음은 이어집니다. 새 문맥으로 시작하려면 **서비스 종료** 후 **번역 시작**을 눌러 주세요.

자동 통역은 말을 잘못 알아듣거나 다른 언어로 전사할 때가 있습니다. 예배 전 점검에서는 원문과 번역을 함께 확인해 주세요.

## 12. 녹음과 설정을 나중에 확인할 때

입력 음성은 다음 폴더에 MP3로 저장됩니다. 번역을 일시정지한 동안에도 녹음은 계속됩니다.

```text
logs/recordings/current_week/
```

새 녹음이 시작될 때 21일이 지난 녹음 파일을 정리합니다. 나중에 필요한 음원은 다른 폴더에 복사해 보관해 주세요. 녹음 경고가 나오면 MP3가 저장되지 않을 수 있으므로 예배 전에 확인하는 것이 좋습니다.

전사와 세션 요약은 `logs/sessions/`에 있습니다. 영상과 맞출 때는 녹음 시작 시각을 먼저 확인해 주세요. 전사 시각에는 통역이 도착하기까지의 지연이 포함됩니다.

시작이 느리거나 오류가 생기면 `logs/startup.log`와 `logs/ops.log`를 문제 확인에 사용할 수 있습니다. 평소 실행할 때 자동으로 기록되므로 별도 진단을 실행하지 않아도 됩니다.

교회 이름, 로고, 현장 주소나 API 키를 바꿀 때는 `SKC_setup.exe`를 다시 실행합니다. 기존 키를 바꾸려면 **Replace Key...** 버튼을 누르면 됩니다. 현장 주소를 바꾸었다면 QR 안내문도 새로 배포해 주세요.

업데이트 후 문제가 생기면 새 프로그램을 종료하고 보관해 둔 이전 폴더의 `SKC_translation.exe`를 실행할 수 있습니다.

최신 버전과 업데이트 내용은 아래 GitHub 프로젝트에서 확인할 수 있습니다.

[github.com/starkville-kch/live-translation](https://github.com/starkville-kch/live-translation)

# 포함된 구성 요소 고지

이 프로그램의 MP3 녹음은 수정하지 않은 `lameenc 1.9.0`과 그 안에 포함된 LAME 인코더를 사용합니다. 별도 FFmpeg 실행 파일은 포함하지 않습니다.

- lameenc 소스 및 빌드 안내: https://github.com/chrisstaite/lameenc
- lameenc 라이선스: LGPL-3.0-or-later, `lameenc-LGPL-3.0.txt`
- LGPL에서 참조하는 GPL 전문: `GPL-3.0.txt`
- LAME 프로젝트: https://lame.sourceforge.io/

인터넷 접속용 `cloudflared.exe`는 배포 ZIP에 넣지 않으며 설정 마법사에서 다운로드합니다. 아래 고지는 이전에 동봉했던 수정하지 않은 `2026.10.4` 파일의 기록입니다. 새 다운로드의 버전·해시가 아래와 같다는 뜻은 아닙니다.

- Cloudflare 소스 및 라이선스: https://github.com/cloudflare/cloudflared/tree/2026.10.4
- Apache License 2.0 원문: `cloudflared-LICENSE.txt`
- 실행 파일 SHA-256: `411b16d40c8d872243efeb52c550053d00af0a8a97fbb32e730fb8aba429eaa8`

이 폴더는 구성 요소의 고지와 라이선스 원문을 보관합니다. 교회 설치 폴더에 자동으로 배포하지 않았습니다.

SKC 실시간 번역 자막 시스템 가이드

SKC Live Translation — Volunteer Guide

예배의 모든 순서를 실시간 한영 번역 자막으로 전달하기 위한 안내서입니다. 오디오 입력 설정부터 AI 번역 구동, 그리고 자막 방송 운영 절차까지 필요한 모든 내용을 안내합니다.

This volunteer guide serves to ensure every grace-filled moment of the service is beautifully conveyed through real-time Korean-to-English translation. Find everything you need to configure audio capture, launch the Gemini AI translator, and manage live caption streams.

시스템 작동 원리

How the System Works

목사님용 무선 핀마이크와 단상 마이크 등의 소리를 믹서에서 받아 PC가 캡처합니다. 이후 구글 제미나이 Live API구글의 실시간 인공지능 번역 및 음성 합성 모델 서비스Google's real-time AI translation and speech synthesis model service를 통해 실시간으로 번역하고, 번역된 텍스트와 오디오(24kHz PCM압축되지 않은 디지털 오디오 원음 포맷Uncompressed raw digital audio format)를 교회 내부 와이파이(WiFi)를 통해 참석자들의 폰으로 전송합니다. 참석자는 QR 코드를 스캔하여 브라우저에서 편리하게 자막과 오디오(선택 가능)를 이용할 수 있습니다.

Audio from independent wireless lapel mics (pastor & podium) is captured on this local Windows PC, streamed to Google Gemini Live API구글의 실시간 인공지능 번역 및 음성 합성 모델 서비스Google's real-time AI translation and speech synthesis model service for real-time translation, and broadcasted as live text captions (SSE서버가 클라이언트로 자막을 실시간 전송하는 프로토콜Lightweight unidirectional server-push caption streaming protocol) and audio streams (WebSocket) to attendee phones over the church WiFi. Attendees scan a QR code to connect instantly.

주일 예배 운용 절차 (Workflow)

Every-Service Workflow

1. 마이크 연결 및 프로그램 실행

1. Connect Microphone & Start Program

사운드 믹서 또는 USB 마이크를 PC의 USB 포트에 연결한 후, 바탕화면의 SKC 실시간 번역 아이콘 또는 SKC_Live_Translation.exe를 실행합니다. 실행 시 운영자 콘솔 브라우저 화면이 자동으로 열립니다. (검은색 콘솔 창은 예배가 끝날 때까지 닫지 마세요.)

Connect your sound mixer or USB microphone to the PC, then double-click the SKC Live Translation desktop shortcut or SKC_Live_Translation.exe. The operator console browser window will open automatically. (Do not close the background console window until the service is finished.)

2. 마이크 장치 및 모델 확인 후 서비스 시작

2. Verify Device & Model, Click Start

화면의 [입력 장치 설정] 드롭다운에서 예배 마이크/믹서가 선택되어 있는지 확인합니다. (새로 꽂은 장치가 안 보이면 🔄 버튼을 누르세요.) 마이크를 테스트할 때 아래 레벨 미터(Level Meter)가 초록색으로 반응하는지 확인한 후, ▶ 번역 시작 (Start) 버튼을 누릅니다. 수 초 내로 상태 표시가 작동 중 (LIVE)으로 바뀝니다.

Confirm your microphone/mixer is selected in the [Input Device] dropdown. (Click 🔄 if newly plugged in.) Verify that the level meter responds to speech, then click ▶ Start. The status indicator will transition to Live within a few seconds.

3. 참석자들에게 QR 코드 공유

3. Share QR Code with Attendees

관리자 화면 우측에 표시된 QR 코드는 참석자들이 자막과 음성 통역을 이용할 수 있는 전용 주소(http://skc.local)입니다. 예배당 입구 배너, 주보, 또는 스크린에 띄워 공유해 주세요. 참석자들은 스마트폰 카메라로 QR 코드를 스캔하여 별도 앱 설치 없이 브라우저에서 바로 실시간 자막과 음성 통역(이어폰 착용 권장)을 이용할 수 있습니다.

The QR code on the operator dashboard directs attendees to the live caption page (http://skc.local). Display it on sanctuary screens or handouts. Attendees simply scan the QR code with their smartphone camera to view live captions and listen to voice interpretation (earphones recommended) without installing any app.

4. 예배 종료 후 안전한 종료

4. Stopping & Exiting After Service

예배가 끝나면 ■ 서비스 종료 (Stop) 버튼을 누릅니다. 해당 예배의 한영 대조 전사록이 logs/sessions/ 폴더에 자동 저장됩니다. 이후 하단의 [⏻ Exit System] 버튼을 누르면 서버 프로그램이 안전하게 종료됩니다.

When the service finishes, click ■ Stop. The sermon transcript will be automatically exported under logs/sessions/. Then click [⏻ Exit System] at the bottom to shut down the server safely.

오류 및 문제 해결 가이드

Troubleshooting Guide

1. 마이크 소리가 전달되지 않거나 레벨 미터가 움직이지 않는 경우

1. Level Meter does not move when speaking

관리자 콘솔 화면에서 [입력 장치 설정] 드롭다운에 실제 믹서나 마이크가 선택되어 있는지 확인하세요. 새로 연결한 장치가 목록에 안 보이면 바로 옆의 🔄 새로고침 버튼을 누르면 즉시 감지됩니다.

Verify the correct mixer or USB microphone is selected in the [Input Device] dropdown. If a newly plugged device does not appear, click the 🔄 button to rescan audio devices.

2. 예배 도중 자막 번역이 잠시 멈추는 경우

2. Captions pause briefly mid-service

Gemini Live API의 10분 연결 주기 갱신으로 인해 2~3초간 노랑 (Reconnecting) 상태가 되는 것은 정상적인 자동 복구 과정입니다. 만약 빨강 (Error) 상태가 지속되면 인터넷 연결을 확인하고 ■ Stop ➔ ▶ Start를 다시 눌러주세요.

A brief 2–3 second Amber (Reconnecting) state every ~10 minutes is normal auto-refresh behavior. If the status stays on Red (Error), check your internet and click ■ Stop ➔ ▶ Start.

3. 잘못된 언어(일본어/베트남어 등)로 잘못 인식되거나 오번역이 지속되는 경우

3. Model gets stuck in the wrong language (Language Drift)

찬양, 웅성거림, 또는 음향 노이즈로 인해 AI가 한국어가 아닌 다른 언어(일본어, 베트남어 등)로 잘못 감지하여 오번역이 연속될 수 있습니다.
• 즉시 수동 교정: 화면 중앙의 ⏸ 일시정지 (Pause)를 누른 뒤 1~2초 후 ▶ 번역 다시 시작 (Resume)을 누르면 세션이 초기화되어 즉시 정상 한국어로 교정됩니다.
• 자동 교정 기능: 운영자 콘솔의 [자동 언어 오류 복구]를 ⚡ Auto로 켜두시면 시스템이 연속된 비정상 언어 감지 시 스스로 세션을 리셋하여 자동으로 정상 복구합니다.

Acoustic noise, music, or background chatter can occasionally cause the AI to hallucinate and drift into another language (e.g., Japanese or Vietnamese).
• Manual Fix: Click ⏸ Pause and then click ▶ Resume after 1–2 seconds. This resets the active context and immediately returns to clean Korean translation.
• Automatic Correction: Set [자동 언어 오류 복구] to ⚡ Auto on the operator dashboard. The server will automatically detect sustained drift and self-recover within 2 seconds without operator intervention.

4. 참석자 스마트폰이 자막 페이지에 접속되지 않는 경우

4. Attendees cannot load the caption page

공용 HTTPS(QR 코드)를 이용하면 LTE/5G에서도 바로 접속할 수 있습니다. 로컬 주소(http://skc.local:8080) 접속 시에는 모든 참석자의 스마트폰이 교회 내부 와이파이(Church WiFi)에 연결되어 있어야 합니다.

Attendees can connect from cellular data (LTE/5G) via Public HTTPS (QR code). For local network addresses (http://skc.local:8080), phones must be connected to the Church WiFi network.

보안 주의: .env 설정 파일을 외부에 공유하지 마세요. 교회 전용 Gemini API 키가 포함되어 있습니다.
Security Warning: Keep your .env file secure. It contains your church's private Gemini API key.

예배 전사록 보관 및 로그 파일

Export Transcripts & Session Logs

이전 예배의 통역 기록을 확인하려면 프로그램 폴더 안의 logs/sessions/ 폴더를 확인하세요. 각 세션마다 예배를 중지한 시간에 맞춰 원문 전사록(ko.txt), 번역 자막(en.txt), 그리고 시간대별 대조본(aligned.txt)이 깔끔하게 저장됩니다.

To review sermon translation records, check the logs/sessions/ directory. Every completed session automatically saves source transcripts (ko.txt), translated captions (en.txt), and aligned study files (aligned.txt).
